About Me

Hi! I'm Carls Jr, a User Interface / Product designer and frontend developer from the Philippines with 7+ years of experience. I graduated BS – Computer Science at La Salle University. I have work experience as a Senior Creative Director on Creative Agency. I'm available for freelance work in Web design, Mobile / Tablet Design (iOS & Android), (UI) User Interface design, (UX) User Experience design, Logo design and Front End development (CSS3 / HTML5). I specialize in creating websites that does not only focus on the visual interface design but it also conforms on the latest web standards.

I have work with clients from Australia, US, New Zealand, UK, Ireland, France, Canada, Russia, Spain, Sweden, Germany, Switzerland, Dubai and Singapore. I can design clean, minimalist, corporate and responsive websites that are W3C compliant. I can also create brand logo, poster, business card and other materials for both web & print. I have experience in using Photoshop, Illustrator, Sketch, coding CSS3 / HTML5 with LESS (responsive / adaptive) and have some basic knowledge with Jquery on designer’s point of view.
